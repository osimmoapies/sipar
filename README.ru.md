# Sipar — язык для ИИ-агентов с защитой от внедрённых команд

«Сипар» по-таджикски — «щит». [English](README.md)

![Письмо со скрытым приказом заставляет модель вызвать команду; Sipar блокирует вызов](docs/injection.gif)

**Главная идея.** Всё, что пришло от модели, с сайта, из файла или из команды, получает метку
«недоверенное». Такие данные не могут попасть в опасное действие: запустить команду, записать файл,
открыть адрес. Снять метку можно двумя способами: `trust(x, "почему")` — код сам ручается за данные
и пишет причину в журнал; `approve(x, "вопрос")` — человек смотрит на данные и подтверждает.
Секреты (`env.secret` + `allow secret [...]`) получают метку «секрет»: вывести их, записать в файл,
отправить в промпт или в `json.encode` — ошибка; в журнале и в тексте ошибок вместо значения стоит
`«secret:ИМЯ»`.
Внедрённый в письмо приказ может заставить модель *сказать* что угодно. Чтобы этот текст стал действием,
нужна проверка, которую написали вы.

**Что ещё есть:**
- типизированные ИИ-функции (`ai fn`): ответ проверяется по типу, при ошибке — повтор;
- агенты с инструментами (`agent fn` + `tools [...]`);
- права (`allow net [...]`, `allow fs.write [...]`, `allow shell [...]`);
- бюджеты (`budget(ai_calls:, tokens:, usd:, seconds:)`);
- журнал каждого запуска и точный повтор (`sipar replay`);
- тесты с подменой модели (`test` + `mock`);
- понятные ошибки с кодами;
- память, которая помнит метки; запасные модели; отчёт о расходах (`sipar trace`); вызов из Python;
- MCP-серверы: `allow mcp "fs" [...] tools [...]` — программа зовёт только перечисленные инструменты,
  каждый ответ получает метку `untrusted:mcp:<сервер>/<инструмент>`, описания инструментов закреплены
  (`pin`) против подмены (`examples/mcp/`, SPEC.md §7a);
- `sipar lsp` — языковой сервер (LSP, stdio) для любого редактора; `editors/vscode/` — расширение VS Code
  с подсветкой, которое запускает этот сервер (путь к `bin/sipar` задаётся в настройке `sipar.path`);
- ноль зависимостей: нужен только Python 3.12+.

**Запуск:**
```sh
git clone https://github.com/osimmoapies/sipar && cd sipar
python3 -m sipar check examples/triage.sipar                  # проверка типов и прав без запуска
python3 -m sipar test examples/triage.sipar
SIPAR_MODEL=mock python3 -m sipar run examples/triage.sipar
SIPAR_MODEL=mock SIPAR_MOCK_SCRIPT=examples/injection/hijacked_model.json \
  python3 -m sipar run examples/injection/assistant.sipar     # атака → BLOCKED (taint)
```

**Установка:** `pip install git+https://github.com/osimmoapies/sipar` (Python 3.12+, macOS или Linux;
на PyPI пока нет).

**Чего Sipar не делает.** Не следит за ветвлениями (`if`, `match`): значения `Bool` и `enum` идут без
меток, поэтому внедрённый текст может повлиять на выбор ветки — одной из тех, что написали вы. Не
проверяет, правдив ли текст, который показывает `print`. Это не песочница: разрешённая команда работает с
правами вашего пользователя. Версия 0.1 (альфа): внешнего аудита и формального доказательства пока нет,
на AgentDojo язык не измерялся.
